# Instruções do projeto ShopVax para agentes / Codex

Este repositório JÁ possui uma aplicação real. **Continue o trabalho existente; NÃO reinicie nem reescreva a aplicação.**

Leia antes de qualquer alteração: [`docs/CODEX_HANDOFF_FINALIZACAO.md`](docs/CODEX_HANDOFF_FINALIZACAO.md), depois `README.md`, `docs/references/README.md`, `docs/SHOPVAX_RELEASE_GATE.md` e `package.json`.

- Escopo comercial e funcionalidades vigentes são as decisões posteriores e regras reais de API/DB, não preços antigos do manifesto.
- Visual obrigatório: arquivos originais ZIP de marca + redesign em `docs/references/`; o redesign completo está dividido em partes remontáveis em `redesign-original-parts/`.
- Preserve isolamento multiempresa, histórico de pedidos, plano e limites, origem de vendedora, WhatsApp, concorrência/estoque, dados e produção.
- GitHub Actions verde não é homologação real de VPS ou equivalência visual com a fonte.
- Não inserir segredos, dados reais de clientes nem capturas sensíveis em commits.
- Ao modificar funcionalidades, adicione e execute testes; informe SHA, evidencia e pendências sem exagerar status.
