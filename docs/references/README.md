# Referências originais do ShopVax — acervo para o Codex

Esta pasta reúne materiais de produto e identidade visual historicamente fornecidos/aprovados para o ShopVax. **Não substitui o código nem a configuração de produção.**

## Fontes disponíveis neste repositório

- [Manifesto do MVP — transcrição textual](Shopvax_Manifesto_MVP.texto.md): conteúdo textual do PDF `Shopvax_Manifesto_MVP.pdf`, anterior às diretrizes comerciais mais recentes.
- [Diretrizes de produto e preços — transcrição textual](Atacado_Shop_Diretrizes_Produto_e_Precos.texto.md): conteúdo textual do PDF `Atacado_Shop_Diretrizes_Produto_e_Precos(1).pdf`, de 29/08/2026. Existe cópia duplicada com final `(2)`; não foi publicada em dobro.
- [Logotipo — fontes SVG oficiais](Shopvax_Logo_propostas.zip): arquivo ZIP original `Shopvax_ Logo (propostas).zip` do Google Drive, com pranchas vetoriais, incluindo `19 · Laranja.svg`.
- [Logotipo — previews PNG](Shopvax_Logo_previews_png.zip): arquivo ZIP original `Shopvax_ Logo (propostas) (2) png.zip`, com pranchas PNG.

## Material de redesign ainda no Google Drive

O Codex deve obtê-lo via Drive autorizado ou solicitar seu upload antes de declarar homologação visual pixel a pixel. ## Precedência e segurança

Decisões comerciais atuais explícitas prevalecem sobre o manifesto histórico. Não reverter planos/preços por ler uma fonte antiga.

Os repositórios GitHub podem ser públicos. Não adicionar capturas de WhatsApp, dados pessoais, conversas de clientes, segredos ou credenciais sem uma revisão de privacidade e autorização adequada.
